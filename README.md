## 📌 Overview

This project processes raw IPL ball-by-ball data using **Apache PySpark** and presents the insights through a **Streamlit** dashboard with interactive **Plotly** charts. The pipeline aggregates the data into lightweight CSVs which power the dashboard — no Spark or Java needed at runtime.

---

## ✨ Features

| Tab | What It Shows |
|---|---|
| 📊 **Overview** | Total matches, runs, balls, wickets · Season-wise runs · Wicket types · Match results |
| 🏏 **Batters** | Top N batters by runs · Strike rate bubble chart · Runs distribution by over |
| 🎳 **Bowlers** | Top N bowlers by wickets · Economy vs wickets · Wicket fall by over |
| 🏆 **Teams** | Team total runs & RPM · Toss decision breakdown · Year-wise team trends |
| 📅 **Season Trends** | Runs · Sixes & fours · Wickets · Average score — all per season |

## ⚙️ Quick Start

```bash
# 1. Install dependencies
pip install -r requirements.txt
pip install pyspark==3.5.1

# 2. Run the pipeline to generate data/
python ipl_pipeline.py --data IPL.csv --out data

# 3. Launch the dashboard
streamlit run app.py
```
